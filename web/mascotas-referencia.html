Mascotas de referencia para Kodama

Idea de LShinox: una mascota útil tipo Clippy para los chats de Claude. Fecha: 13-oct-2026. Las imágenes cargan desde GitHub (hace falta internet).

Solo referencia: no se reusa arte ni código con licencia restrictiva.

1. clawd-on-desk

github.com/rullerzhou-afk/clawd-on-desk · web: clawdondesk.com · Electron · código AGPL-3.0 · arte aparte (Clawd es de Anthropic)

El README también enlaza un video de demo multi-monitor (ver en GitHub); no es un enlace directo al archivo, por eso no se incrusta.

Qué hace

  • 12 estados: reposo, pensando, tecleando, construyendo, 1 subagente, malabares con varios, error, feliz, notificación, barriendo, cargando, dormido.
  • Reacciona a Claude Code, Codex CLI y otros agentes mediante hooks que se registran solos.
  • Burbuja flotante Permitir/Denegar con atajos globales (Ctrl+Shift+Y/N); modo No molestar.
  • Varias sesiones: se muestra el estado de mayor prioridad; detecta procesos huérfanos.
  • Se arrastra al borde (modo mini), se duerme a los 60 s con bostezo y despierta sobresaltado; en reposo los ojos siguen el cursor.
  • Instalación: instalador .exe en GitHub Releases (Windows, también macOS y Linux). Temas con theme.json.

Idea para nosotros

  • Copiar el concepto, no el código ni a Clawd: tabla corta de estados (pensando, trabajando, esperando permiso, error, éxito, dormido) con nuestro propio personaje.
  • La burbuja "Permitir / Denegar" es justo lo que hace útil a un Clippy: la mascota avisa que Claude espera algo y deja contestar desde ahí.
  • Prioridad de estado entre varios chats y modo mini al borde para no estorbar.
  • Al ser AGPL, solo lo usamos como inspiración funcional.

2. OpenPets

github.com/OpenPetsHQ/openpets · web: openpets.dev · Electron + TypeScript · MIT

Qué hace

  • Mascota de escritorio para agentes (Claude Code, OpenCode, Devin) con galería de mascotas.
  • Estados: pensando, editando, probando, éxito, error, esperando; en reposo: quieta, paseando, reaccionando.
  • Servidor MCP (openpets_status, openpets_react, openpets_say) para que el propio agente haga hablar a la mascota; SDK de plugins.
  • Varias sesiones: cada sesión toma su mascota libre de un grupo (pool).
  • Windows: reafirma "siempre encima" cada 1 s para que no la tape una app a pantalla completa.
  • Instalación: OpenPets-*-win-x64-setup.exe en Releases; integración opcional con una línea de configuración MCP. Plataformas: Windows, macOS, Linux.

Idea para nosotros

  • Que la mascota hable por una herramienta (tipo say/react): así Claude puede dar avisos útiles reales, no solo animaciones.
  • Una mascota por chat, con enfriamientos para no repetir frases, y frases tomadas de listas fijas (sin copiar texto real del chat).
  • Patrón MIT de "siempre encima" cada segundo: adaptable con nuestro propio código.

3. claude-pet (IMMINJU)

github.com/IMMINJU/claude-pet · sin web propia · Tauri 2 (~8 MB) · MIT · pocas estrellas (12)

Este README solo tiene una imagen real (la demo); el resto son insignias. Las otras temas (por ejemplo "Fruits") se mencionan sin imagen.

Qué hace

  • Emoji o animación con globo de texto según 17 estados (leer, escribir, bash, buscar, error, esperar...).
  • Varias sesiones de Claude Code lado a lado, una mascota por sesión.
  • El hook claude-pet --hook manda el evento por TCP local (127.0.0.1:19876); los hooks se registran solos al arrancar.
  • Ventana sin marco, transparente, siempre encima y fuera de la barra de tareas.
  • Instalación: script PowerShell (install.ps1) a %LOCALAPPDATA%\claude-pet. Windows, macOS, Linux.

Idea para nosotros

  • Es la plantilla más chica y clara de la ruta Tauri en Windows: un hook diminuto + puerto local + ventana transparente.
  • Globo de texto corto por estado ("leyendo archivos...", "esperando tu OK") como base del Clippy útil.
  • Tomarlo como ejemplo de arquitectura, no como dependencia (proyecto muy joven).
